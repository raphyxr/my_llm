# Building My Own Language Model with PyTorch

**An independent AI research and development project**

I'm a 15-year-old French student passionate about artificial intelligence and software development. For the past year, I've been working on a personal project: understanding how large language models work by building my own language model from scratch using PyTorch.

Rather than simply using existing AI models, my goal is to understand the technology behind them and experiment with implementing it myself.

## About the Project

The project started as an exploration of how computers can learn language from text.

I began with simpler neural network architectures and progressively moved towards Transformer-based models, exploring the concepts behind modern LLMs.

My main objective is to develop a language model capable of understanding and generating French text.

## Technical Overview

The project is built primarily with:

- **Python** – Main programming language.
- **PyTorch** – Neural network implementation and training.
- **Transformers** – Attention-based architecture for language modelling.
- **CUDA** – GPU acceleration for training when available.

Some of the configurations explored during development include:

| Component | Configuration |
|---|---|
| Architecture | Transformer |
| Embedding dimension | 128 |
| Context length | 128 tokens |
| Vocabulary size | 200,001 tokens |
| Transformer layers | 24 |

These values describe one of my experimental configurations and may evolve as development continues.

## What I've Learned

Working on this project has allowed me to explore several areas of machine learning:

- Tokenization and vocabulary construction.
- Word and token embeddings.
- Neural networks and backpropagation.
- Self-attention mechanisms.
- Transformer architecture.
- Model training, validation and loss evaluation.
- GPU computing and memory optimization.
- Checkpointing and resuming training.

I've also experimented with training models on larger datasets and dealing with the computational limitations of available hardware.

## Current Status

This is an ongoing experimental project.

I'm continuously working on improving the architecture, understanding training behaviour and making better use of limited computing resources.

The project is primarily educational and experimental rather than a production-ready language model.

## Why I'm Building This

I'm particularly interested in understanding AI beyond simply using existing models.

Building a language model from scratch has been a way for me to learn about the mathematics, programming and engineering behind modern AI systems.

I hope to continue exploring machine learning, neural networks and AI research in the future.
